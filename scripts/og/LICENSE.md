# Fonts used by the Open Graph card build (scripts/og/build-og.tsx)

Static TTF subsets fetched from Google Fonts for `scripts/og/build-og.tsx`, which renders `public/og.png` at build time and cannot rely on the network.

- Space Grotesk 600, Florian Karsten. SIL Open Font License 1.1.
- Inter 500, Rasmus Andersson. SIL Open Font License 1.1.
- JetBrains Mono 400, JetBrains. SIL Open Font License 1.1.
